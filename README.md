# Arena das Sombras

Bem-vindo ao repositório oficial de Arena das Sombras! Um jogo de luta 2D com estilo retrô, criado com HTML, CSS e JavaScript puro, inspirado nos clássicos dos fliperamas.

## 📖 Sobre o Jogo

Entre na arena neste explosivo jogo de luta arcade retrô! Inspirado nos clássicos, mergulhe em combates 2D com gráficos pixelados vibrantes. Escolha seu guerreiro, domine habilidades únicas e conquiste o torneio secreto.

Uma entidade misteriosa convocou os lutadores mais poderosos para um torneio clandestino. Cada competidor carrega suas próprias motivações — honra, redenção ou poder absoluto.

## ✨ Recursos
* **Ação Arcade Clássica:** Jogabilidade 2D fluida e responsiva.
* **Três Lutadores Únicos**: Cada um com suas próprias habilidades especiais e estilo de luta.
* **Modo História:** Siga a jornada do seu personagem e veja um final exclusivo para ele.
* **Modo Versus Local:** Desafie um amigo para um combate um contra um no mesmo teclado.
* **Estilo Retrô Autêntico:** Gráficos e sons que te transportarão de volta à era de ouro dos arcades.

## 🎮 Controles do Jogo

| Ação          | Jogador 1              | Jogador 2   |
|---------------|------------------------|-------------|
| **Movimento** | Setas Direcionais      | A / D       |
| **Pulo**      | Seta para Cima         | W           |

| **Ataque Forte** | M                   | H           |
| **Especial**  | , (vírgula)            | T           |
| **Defesa**    | . (ponto)              | Y           |

## Como Iniciar uma Partida
1. Na tela de seleção, o **Jogador 1** escolhe seu personagem.

2. **Para jogar contra o CPU (Modo História):** Após a escolha, pressione uma tecla de ataque (N ou M).

3. **Para jogar contra um amigo (Modo Versus):** O **Jogador 2** escolhe um personagem diferente para iniciar a batalha.

## 🔧 Configuração
Nenhuma configuração é necessária! O jogo é um único arquivo html autocontido e não possui dependências externas que precisem de instalação. Apenas abra o arquivo em um navegador e jogue.

## 🚀 Como Executar o Jogo
1. Clonar ou baixar este repositório.

2. Abrir o arquivo arena_das_sombras.html em qualquer navegador moderno (Google Chrome, Firefox, etc.).

3. Pronto! O jogo começará a rodar.

## 🛠️ Tecnologias Utilizadas
* **HTML5**

* **CSS3** (com Tailwind CSS)

* **JavaScript** (Vanilla)

* **Tone.js** para a geração de efeitos sonoros.
