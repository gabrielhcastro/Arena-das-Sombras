# Arena-das-Sombras
Entre na arena neste explosivo jogo de luta arcade retrô! Inspirado nos clássicos, mergulhe em combates 2D com gráficos pixelados vibrantes. Escolha seu guerreiro, domine habilidades únicas e conquiste o torneio secreto. Inclui modo história com finais exclusivos e modo versus local para desafiar seus amigos.
